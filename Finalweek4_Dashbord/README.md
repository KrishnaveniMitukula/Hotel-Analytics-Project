# 📊 Week 4: Business Intelligence Dashboard

## Dashboard Overview
This interactive Power BI dashboard visualizes 119,000+ hotel booking records to provide actionable insights for the Revenue Management team. The dashboard features real-time filtering capabilities using interactive slicers.

## 📈 Dashboard Pages

### Page 1: Executive Overview
![Executive Overview](DAshboardpage%281%29.png)

This page provides a high-level summary of key business metrics:
- **Total Bookings:** 119K+ bookings analyzed
- **Total Cancellations:** 44K+ cancellations identified
- **Cancellation Rate:** 37.2% of all bookings are canceled
- **Average Daily Rate (ADR):** $102.40 per night
- **Average Lead Time:** 104 days before arrival

### Page 2: Customer Segmentation & Trends
![Customer Segmentation](Dashboardpage%282%29.png)

This page provides a deeper breakdown of customer behavior & booking patterns across different segments.

## 🔍 Key Insights Discovered
1. **Lead Time** is the strongest predictor of cancellations — longer advance bookings cancel far more frequently
2. **Online Travel Agencies** (Expedia, Booking.com) account for 46.9% of all cancellations
3. **Non-Refundable Deposits** nearly eliminate cancellations entirely
4. **Summer months** (July-August) generate the highest Average Daily Rate

## 🛠️ How to Use
1. Download the `hotel_report.pbix` file
2. Open it in Microsoft Power BI Desktop
3. Use the **Hotel Type Slicer** (top-right) to filter between City Hotel and Resort Hotel
4. Click on any chart element to cross-filter all other visuals
